# 🍏 Hoai iPhone Clone

A modern **React + Vite** front-end project replicating Apple's product showcase style — smooth animations, 3D elements, and responsive design.

---

## 🚀 Live Demo

🔗 **Live site:** [https://hoainb1303.github.io/hoai.ip.clone](https://hoainb1303.github.io/hoai.ip.clone)

---

## 🧩 Tech Stack

- ⚛️ **React 19**
- ⚡ **Vite** (for fast dev & builds)
- 🎨 **TailwindCSS**
- 🎬 **GSAP** for animations
- 🧱 **Three.js / React Three Fiber** for 3D effects

---

## 🛠️ Installation & Setup

Clone this repository and install dependencies:

```bash
git clone https://github.com/hoainb1303/hoai.ip.clone.git
cd hoai.ip.clone
npm install
```
